# Trios — Try Yours

Your next opportunity starts here.

Trios is a full-stack job discovery and professional networking platform designed to connect job seekers, recruiters, and professional communities.

Planned features

- Job discovery, search, and filtering
- Professional profiles and CV uploads
- Job applications and saved jobs
- Recruiter and company dashboards
- Professional posts, connections, and messaging
- Notifications and job alerts
- AI-powered career assistance
- Admin dashboard and moderation

Design

- Primary colour: dark green
- Clean, modern, responsive interface
- Desktop and mobile support

Status

🚧 In development.
